# BVHpractice-Unity-Demo
Unity BVH骨骼动画播放器Demo

## 项目简介
这是一个基于Unity实现的BVH动作文件解析与播放演示项目，可以加载BVH骨骼动画，支持动画播放速度调节、动画重置功能。

## 功能
- ✅ 读取并解析BVH骨骼动画文件
- ✅ 动画播放 / 暂停
- ✅ 播放速度滑块调节
- ✅ 一键重置动画到起始帧

## 开发环境
- Unity 版本：2022.x
- 脚本语言：C#

## 使用说明
1. 将项目下载到本地，用Unity打开
2. 打开演示场景
3. 导入BVH动作文件，即可预览骨骼动画
4. 在UI面板调整播放速度、重置动画

## 备注
本项目为数字媒体技术课程练习Demo。
